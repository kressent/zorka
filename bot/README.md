# 🤖 Зорька-бот (Telegram)

Автоматизация охвата: бот отвечает прогнозом клёва на название города/водоёма,
а `daily.js` сам постит ежедневный прогноз в канал. Использует тот же движок,
что и приложение (`js/score.js`, `js/weather.js`). Без внешних зависимостей.

## Что нужно от тебя (один раз, ~2 минуты)
1. Открой в Telegram **@BotFather** → `/newbot` → задай имя и юзернейм (напр. `zorka_klev_bot`).
   BotFather пришлёт **токен** вида `123456:ABC-...`.
2. (для авто-постинга в канал) Создай Telegram-канал, добавь бота **администратором**,
   узнай его id: либо `@username_канала`, либо числовой (через @getidsbot).

## Запуск

**Бот-ответчик** (отвечает на «Уфа», «прогноз Салават» и т.п.):
```bash
# Windows PowerShell:
$env:ZORKA_BOT_TOKEN="ВАШ_ТОКЕН"; node bot/bot.js
# bash:
ZORKA_BOT_TOKEN=ВАШ_ТОКЕН node bot/bot.js
```

**Ежедневный постер в канал** (по водоёмам из `bot/places.js`):
```bash
node bot/daily.js --dry     # тест: печатает посты в консоль, ничего не шлёт
# боевой:
$env:ZORKA_BOT_TOKEN="ТОКЕН"; $env:ZORKA_CHANNEL="@ваш_канал"; node bot/daily.js
```
Поставь `daily.js` на расписание (Планировщик задач Windows / cron), напр. в **18:00** —
и канал сам публикует прогноз на завтра. Список водоёмов правится в `bot/places.js`.

## Заметки
- Пока движок на правилах — со временем прогноз уточнится на реальных уловах (когда подключим сервер).
- Не спамь этим в чужие чаты/форумы — там банят рекламу. Бот и канал — это «наши» площадки.
