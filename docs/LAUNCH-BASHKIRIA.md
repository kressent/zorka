# 🎣 Запуск в Башкирии — Telegram-first (готовый арсенал)

> Стартовый рынок — **Башкортостан** (база Салават, охват — вся республика).
> Канал первый: **Telegram** (у тебя есть аккаунт). ВК/ОК — позже, когда восстановишь
> доступ. Принцип один: **не «скачай приложение», а «вот тебе польза»** — сначала
> бесплатный прогноз, потом люди сами спрашивают, где это.

Ссылка приложения: **https://kressent.github.io/zorka/**

---

## Шаг 1. Бот-«пробная таблетка» (5 минут, нужен ты)
Код готов (`bot/`). Бот мгновенно отвечает прогнозом на водоём/город — идеальная
первая ценность.

1. Telegram → **@BotFather** → `/newbot`
2. Имя: **На крючке — клёв** · username: например `nakryuchke_bot`
3. Получишь токен `123456:ABC…` → **пришли его мне** (впишу в запуск) или запусти сам:
   ```
   ZORKA_BOT_TOKEN=твой_токен node bot/bot.js
   ```
4. В настройках бота (@BotFather → Edit Bot) поставь:
   - **About:** Прогноз клёва на любой водоём Башкирии. Что клюёт сегодня и на что.
   - **Description:** Напиши водоём или город — пришлю прогноз клёва на сегодня 🎣
   - **Botpic:** нашу иконку (`icons/icon-512.png`).

## Шаг 2. Канал — «рыбный синоптик Башкирии»
Создай канал. Название (польза цепляет лучше бренда):
- **«Клюёт? · Рыбалка Башкирия»** ← рекомендую
- «На крючке · Башкирия» / «Прогноз клёва · Башкортостан»

**Описание канала:**
> Каждый день — где и на что клюёт в Башкирии 🎣 Прогноз по погоде, давлению, луне и
> воде для Павловки, Нугуша, Белой, Аслыкуля и других. Бесплатно.
> Приложение: kressent.github.io/zorka · Бот: @nakryuchke_bot

**Закреплённый пост:** см. «Пост #0» ниже.

Автопостинг готов: `bot/daily.js` (постер канала, `--dry` для проверки без отправки).

## ⚖️ Правила, чтобы не забанили
- **Не спамь ссылкой.** 80% пользы, 20% ссылки. Модераторы банят за «пришёл и кинул рекламу».
- **Стань своим:** сначала поучаствуй (ответь, выложи отчёт), потом упоминай приложение.
- **Один регион, глубоко.** 30 рыбаков на Павловке > 300 по всей стране: заработает
  «рыба по водоёму» и лента «рядом».
- **Отвечай в комментах.** Живой синоптик, который реально разбирает водоёмы, набирает
  лояльность быстрее любой рекламы.
