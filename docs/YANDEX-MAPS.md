# 🗺 Яндекс.Карты — путь подключения (опция, когда будет ключ)

> Сейчас карта — бесплатный **Leaflet** (спутник Esri + схема OSM), без ключей, работает
> в РФ. Этого достаточно для старта. Яндекс — апгрейд качества спутника/подписей, когда
> появится API-ключ. **Не блокер.**

## Когда есть смысл
- Если рыбакам не хватает детализации спутника/названий по РФ (Яндекс тут сильнее).
- Если уходим в сторы и хочется «родные» карты.

## Что нужно
1. Ключ **JavaScript API и HTTP Геокодер** в
   [Кабинете разработчика Яндекс](https://developer.tech.yandex.ru/services/).
   Бесплатный лимит есть; сверх — платно.
2. Вписать ключ в `js/config.js` (по аналогии с VAPID): `YANDEX_MAPS_KEY: '...'`.

## Как встроим (архитектура уже готова)
Карта изолирована в `js/mapview.js` (initMap/initPicker/drawCatches). Подключение —
адаптер «провайдера карт»:
- если `CONFIG.YANDEX_MAPS_KEY` задан → грузим Яндекс JS API, рисуем слой Яндекса;
- иначе → текущий Leaflet (fallback).
Остальной код (пины, уловы, пикер точки) не меняется — работает через тот же интерфейс.

## Замечания
- Держать **fallback на Leaflet** (офлайн/без ключа/лимит исчерпан).
- Флагов/границ на карте не добавлять (осознанное решение проекта — нейтральность).
- Геокодинг сейчас — Nominatim/OSM (сёла ищет); Яндекс-геокодер можно добавить тем же
  адаптером, если понадобится точность по РФ.
