# Зорька — спецификация (продукт, движок, данные)

Сжатый справочник решений. Обзор и правила — в `../CLAUDE.md`.

## 1. Продукт
Прогноз клёва + дневник + карта мест + снасти для РФ/СНГ (пресноводная рыбалка).
Ядро — «маховик данных»: учимся на реальных уловах, чем больше людей — тем точнее.
Две аудитории (результат / процесс) обслуживаются одним экраном без режимов.

## 2. Движок прогноза (`js/score.js`)
Вход: ответ Open-Meteo (`weather.js`). Для дня считаем `analyzeDay()`:
давление и его тренд, температуры, облачность, дождь, ветер (сила+направление),
температура воды (`waterTemp` — сезонная норма + воздух, с лагом по 10-дневной
истории воздуха), уровень/мутность воды (`waterModel` — «заряд» по 60-дневной
истории осадков с экспоненциальным затуханием τ=12 дн → уровень 0..3 «с памятью»
+ тренд прибывает/держится/спадает; резерв — 3-дневное окно, если истории нет),
«жор» на сломе погоды.

`scoreFish(fish, ctx)` → **абсолютный балл 0..5** + факторы. Учитывает: сезон
(`m` по месяцам), нерест (`sp` → 0 + предупреждение), диапазон воды (`mn`/`mx`),
реакцию на давление (`pU`/`pD`/`pS`), С/В ветер (`wB`), облачность (`cl`), дождь
(`rn`), похолодание, **луну** (глобальный сдвиг), **мутность** (ночные/донные
переносят лучше — `noct`), **жор-буст**.

`computeForecast()` → балл дня = среднее **топ-3 активных** рыб; сортировка видов;
почасовая активность (профили: дневные — зорьки, ночные — ночь); окна клёва;
ближайшие дни; совет.

**Почему так:** старая версия давала «рыба 5 при дне 3», потому что день считался
средним по ВСЕМ видам (несезонные нули занижали). Исправлено: день выводится из
топ-активных; балл рыбы — честное «насколько активна именно она».

## 3. База рыб (`js/data.js`)
15 видов, каждый с ручной настройкой (месяцы активности, нерест, температура,
давление, ветер/облака/дождь, приманки, время, глубина, места, совет, `noct`).
Это перенесённые «мозги» из первой версии — главная накопленная ценность.

## 4. Данные пользователя (сейчас `localStorage`, потом сервер)
- `zorka_settings` — город, фильтр, «своя» подборка.
- `zorka_weather` — кэш погоды (3 ч, офлайн).
- `zorka_diary` — записи: `{date, spot, visited, catches:[{species, weight|null}],
  note, rating, forecast}`. **Вес — по каждой рыбе**; `null` = «не взвешивал»;
  итог считается сам (`entryWeight`).
- `zorka_tackle` — комплекты: `{name, icon, rod, reel, line, target[], lures:[{name,
  type, color, qty, minQty}]}`; напоминание при `qty ≤ minQty`.
- `zorka_places` — места: `{name, depth, note, lat, lon}` (глубина — народная пометка).

## 5. Погода (`js/weather.js`)
Open-Meteo, без ключа. `buildUrl`: hourly (темп., осадки, облачность, давление,
ветер, погода), daily (макс/мин, погода, сумма осадков, ветер, рассвет/закат),
`past_days=2` (мутность/тренд), `forecast_days=7` (планировщик), `timezone=auto`.
Кэш 3 ч в `localStorage` → офлайн. `todayIndex()` находит «сегодня» в массивах.

## 6. Дизайн — «Дневной альманах» (light-only)
Палитра/шрифты/формы — см. `../CLAUDE.md`. Принципы: минимализм + раскрытие по
тапу; всё главное сразу; главный экран полезен, даже если игнорить балл клёва
(есть погода/комфорт). Уход от «скруглённого дефолта».

## 7. Карта
Основной вид — спутник (Яндекс MapKit в приложении); переключатель Спутник/Схема.
Сейчас в вебе — SVG-заглушки. Места показывают народные пометки глубин.

## 8. Что НЕ реализовано (нужны аккаунты/ключи/бэкенд)
Сервер и синхронизация, аккаунты, сообщество и рейтинг приманок, обучение на
данных, распознавание по фото, пуши, спутниковые тайлы Яндекса, RuStore-сборка,
монетизация. См. `ROADMAP.md`.
