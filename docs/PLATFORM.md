# 🧭 Платформа: остаться на PWA или уйти в Flutter — мемо и рекомендация

## Коротко
**Рекомендация: пока остаёмся на веб-PWA.** Мигрировать в Flutter — только когда упрёмся
в конкретные ограничения веба, которые реально мешают росту (а не «на всякий случай»).
Причина: PWA уже закрывает ~90% потребностей, а нативная переписка — это месяцы работы,
которые сейчас лучше вложить в **рыбаков и данные** (маховик), а не в смену стека.

## Что у PWA уже работает
Офлайн (SW), установка на экран «Домой», пуш (Android/десктоп + iOS с экрана «Домой»),
геолокация, карты (Leaflet), шэр-карточки, синхронизация (Supabase). Ноль трения:
открыл ссылку — уже польза, ничего не ставя.

## Где PWA реально жмёт (триггеры для миграции)
| Ограничение | Насколько критично сейчас |
|---|---|
| **iOS-пуши** только с иконки на экране «Домой», капризны | средне — обходится онбордингом |
| **Камера/распознавание рыбы по фото** — в вебе есть, но нативно стабильнее/быстрее | станет важно на этапе фото-фичи |
| **Фоновые задачи** (пуш по прогнозу считаем на сервере — уже обходим) | низко — решено сервером |
| **Присутствие в сторах** (RuStore/Play — доверие, поиск) | средне — решается TWA-обёрткой без переписывания |
| Нет нативных «фишек» (виджеты, Live Activities) | низко |

## Варианты
1. **PWA + TWA-обёртка** (Bubblewrap/PWABuilder) — тот же код, но есть в сторах.
   Дёшево, быстро. **Оптимально на ближайшие месяцы.** См. `docs/STORE-LISTING.md`.
2. **Flutter** — Android+iPhone+веб из одной базы, нативные пуши/камера/фон/виджеты.
   Дорого по времени. Оправдано, когда: (а) фото-распознавание станет ядром UX,
   (б) iOS-аудитория вырастет и пуши/установка начнут терять людей, (в) нужны виджеты/
   Live Activities для удержания.
3. **React Native / Capacitor** — промежуточно; Capacitor умеет обернуть текущую веб-базу
   с нативными плагинами (камера/пуш) без полной переписки. Компромисс, если упрёмся в
   камеру раньше, чем захотим полный Flutter.

## Что переносится в любой стек
Движок прогноза (`score.js`), база рыб (`data.js`), астрономия (`astro.js`), правила —
чистый JS, переезжает куда угодно. Так что «вложение в веб» не пропадёт.

## Решение-триггеры (когда пересматривать)
- Фото-распознавание выходит в ядро → оценить Capacitor/Flutter под камеру.
- Доля iPhone > ~30% и заметный отток на пушах/установке → Flutter/TWA приоритет.
- Появился бюджет/время на 2–3 месяца разработки без ущерба росту.

До тех пор — **PWA + (по готовности) TWA в RuStore**.
