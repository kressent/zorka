# Дорожная карта «Зорьки»

## ✅ Этап 0 — рабочая веб-версия (сделано)
- Дизайн «Дневной альманах», 4 экрана, PWA/офлайн.
- Движок прогноза на правилах + живая погода Open-Meteo.
- Дневник (вес по рыбе + авто-итог), снасти (остаток приманок), карта (места + глубины).
- Данные локально (`localStorage`).

## 🔜 Этап 1 — шлифовка веб-версии
- Пройтись по фидбэку, поправить экраны/тексты.
- Свои иконки Зорьки (сейчас временные от старой версии).
- Проверить название на занятость (домен, сторы, ТЗ).
- Мелочи движка: почасовой график на главном, индикатор уверенности прогноза,
  тип водоёма (река/вдхр/пруд/озеро), геомагнитка (Kp) как слабый фактор.

## 🌐 Этап 2 — сервер и аккаунты (запуск «маховика»)
- **Supabase**: Postgres + PostGIS + авторизация + хранилище фото.
- Перенос данных из `localStorage` в облако, синхронизация между устройствами.
- Схема под обучение: улов = условия (авто из погоды) + что/на что/где (точные
  координаты приватно, огрублённые — публично).
- **Критично для РФ:** оплата/дистрибуция через локальные рельсы (RuStore).

## 🎣 Этап 3 — сообщество и рейтинг приманок
- Лента/карта реальных уловов рядом (приватность мест — по умолчанию).
- **Рейтинг приманок по реальным уловам** («на что сейчас берёт») — наш козырь.
- Отметки «сброс/муть/подъём воды» от рыбаков → в прогноз.
- Модерация/антиспам, доверие к отчётам.

## 🧠 Этап 4 — обучение прогноза на данных
- Гибрид: правила + статистика по регионам, где данных много.
- Позже — ML-модель «вероятность клёва от условий» на реальных уловах.
- Распознавание рыбы по фото (в один тап) — снимает трение внесения = кормит данные.

## 🔔 Этап 5 — удержание и рост
- Пуши: «завтра жор — собирайся», «окно 5–8 утра».
- Красивая карточка улова для шэра (виральность), трофеи, «твой рыболовный год».
- Правила/запреты по региону (баннер в нерест).
- Маркетинг/привычка: «хочется заходить перед каждой рыбалкой» (отдельная проработка).

## 💰 Этап 6 — монетизация (только после реальной пользы)
- Affiliate «купить приманку» + партнёрства с производителями.
- Премиум (детальный прогноз/аналитика), без рекламы. Реклама — по минимуму.

## 🧭 Открытый вопрос: платформа
Сейчас — веб-PWA (быстро, тестируемо, сразу полезно, как старая версия).
Ранее целевым был **Flutter** (Android+iPhone+веб из одной базы, пуши, камера,
сторы, чинит «айфон-проблему» старого веба). Решить осознанно, когда упрёмся в
ограничения веба (пуши/камера/фон/сторы). Часть логики (движок, база рыб)
переносится в любой стек.
