## ✅ Этап 0 — рабочая веб-версия (сделано)
- Дизайн «Дневной альманах», 4 экрана, PWA/офлайн, фирменная иконка.
- Движок: правила + живая погода Open-Meteo, луна в оценке, честный балл дня,
  почасовой график клёва, окна клёва, вода «с памятью» (60 дн осадков + тренд),

- **Бэкенд подготовлен:** схема Supabase + конфиг (ждёт ключи пользователя).

## ⭐ Этап 3.5 — «РЫБА ПО ВОДОЁМУ» (killer-фича, приоритет по полевому фидбэку)
Главный запрос реальных рыбаков (не погода, а): **«какая рыба клюёт на КОНКРЕТНОМ водоёме, и где половить нужный вид»**. За это готовы платить. Развивать:
- Карта водоёмов с community-уловами; тап по воде → что ловится, на что, сезонность.
- Поиск «где ловится форель/карп/…» → места рядом, где этот вид реально брали.
- Профиль водоёма: виды, приманки, лучшие месяцы — из реальных уловов.
Фундамент заложен (nearby.js, огрублённые координаты, вид+приманка в уловах). См. [[rybolov-field-feedback]].
