## ✅ Сделано (фундамент + запуск)
- **Движок:** Open-Meteo + правила, честный балл дня из топ-рыб, почасовой график, окна,
  вода «с памятью», Луна, слом погоды, прогноз на 2 недели, **уверенность прогноза**, **калибровка по реальным уловам рядом**.
- **Приложение:** PWA/офлайн, 4 экрана, «Дневной альманах». Дневник (вес по рыбе, **прикормка**,
  рекорды, «рыболовный год»), снасти, карта (спутник + тап-по-точке + геокодинг сёл).
- **Сервер+аккаунты:** Supabase, вход, синхронизация.
- **Сообщество:** лента по выездам, лайки, комменты, realtime, рейтинг «Уважение», трофеи,
  лидерборды неделя/месяц/сезон, приватность координат, модерация (жалоба на фейк).
- **Рейтинг приманок**, **«рыба по водоёму»** (nearby/профиль/справочник Башкирии), «пригласи друга».
- **Пуши:** лайки/комменты + **«завтра жор»** (forecast-push) + deep-link в комментарии.
- **Запуск:** бот @nakryuchke_fish_bot + канал @nakryuchke_rb — **24/7 на автопилоте**
  (webhook + авто-дайджест + вечерний контент из банка 58 постов). Обратная связь → приватный
  канал в Telegram. **Аналитика событий** (заходы/установки/уловы). Флаеры в магазинах.
- **Бренд:** «На крючке» (классы МКТУ 9/42 свободны).

- Профиль водоёма: виды/приманки/сезонность (есть) → карта водоёмов, «где ловится вид».
- Наполняется уловами сообщества → см. приоритет №1.

## 🎯 Фичи с высоким рычагом (по конкурентам + болям)
- **«Прогноз vs факт»** — показывать, сбылся ли прогноз (у ТипТоп это любят; бьёт в боль №1
  «прогнозам не верят»). Сущности есть — связать явно. Наш козырь доверия.
- **Барометр телефона** — датчик давления для коррекции (как у ddidev94). Техпростая, повышает доверие.
- **Species ID по фото** — распознавание рыбы (Fishbrain/FishVerify — сильный крючок). Снимает
  трение записи → кормит маховик. Сначала «умный шорткат» видов по водоёму/сезону (есть), потом ML/облако.
- **Напарники / совместные выезды** — белое пятно у ВСЕХ конкурентов («ищу компанию на поездку»).
  «Еду туда-то, кто со мной» в ленте. Усиливает и удержание, и данные.
- **«Что сейчас можно/нельзя» по региону** — нерест/нормы/штрафы карточкой (люди боятся; ВНИРО этим силён).
- Явно **коммуницировать приватность** («твои точки видишь только ты») — снимает страх вести дневник.
