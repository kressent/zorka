# 🎣 Паспорт проекта «На крючке»

*Обновлено 2026-08-03. Это краткий обзор: что за проект, что сделано, что впереди.
Подробности — в `ROADMAP.md`, `COMPETITORS.md`, `ANGLER-PAINS.md`, `MARKETING-STRATEGY.md`.*

## Что это
Мобильное веб-приложение (PWA) для рыбаков РФ/СНГ: **прогноз клёва + дневник уловов +
карта мест + сообщество**. Стратегическое ядро — **«маховик данных»**: чем больше рыбаков
ведут дневники, тем точнее прогноз для всех. Старт — Башкортостан, регион за регионом.

**Позиционирование:** *«Показывает, что реально клюёт на твоём водоёме сегодня — по
приметам и по уловам таких же рыбаков рядом, без подписок и без слежки за твоей точкой».*

## Статус: 🟢 ЗАПУЩЕН
Работает приложение + бот + Telegram-канал + ВК-группа (три авто-канала). ~80 версий,
84 авто-теста зелёные. Разработка: 1 человек + ИИ-ассистент, бюджет ≈ 0.

## ✅ Сделано

**Ядро/движок**
- Прогноз на живой погоде: честный балл дня из топ-рыб, почасовой график, окна клёва,
  вода «с памятью» (60 дн осадков + тренд), Луна, слом погоды, прогноз на 2 недели.
- **Уверенность прогноза**, **калибровка по реальным уловам рядом** (обучение v1),
  **«прогноз vs факт»** (сбываемость по личному дневнику).

**Приложение**
- PWA/офлайн, 4 экрана, дизайн «Дневной альманах». Геокодинг сёл, тап-по-карте, спутник.
- Дневник: вес по рыбе, **прикормка**, рекорды, достижения, «рыболовный год».
- Снасти (остаток приманок), карта мест.

**Сервер + сообщество**
- Аккаунты (почта+пароль), синхронизация между устройствами.
- Лента по выездам, лайки, комментарии, realtime, рейтинг «Уважение», трофеи,
  лидерборды неделя/месяц/сезон, приватность координат, **модерация** (жалоба на фейк).
- **Рейтинг приманок** (по реальным уловам), **«рыба по водоёму»** (nearby/профиль/справочник Башкирии).
- **🚗 Напарники / совместные выезды** (фича, которой нет у конкурентов).

**Удержание/виральность**
- Пуши: лайки/комменты + **«завтра жор»** + deep-link. Карточка улова и «рыболовный год» для шэра. «Пригласи друга».

**Запуск/каналы (автопилот)**
- Бот 24/7 (webhook), утренний авто-дайджест, вечерний контент (банк 58 постов) — в TG **и** ВК.
- Обратная связь → приватный Telegram-канал. Аналитика событий. Флаеры в магазинах.

**Инфраструктура/автоматизация**
- Деплой кода при push; функции/секреты/**миграции БД — через CLI ассистентом** (без ручного SQL).
- Ресёрч агентами (конкуренты, боли, SMM, копирайтинг). Бренд «На крючке» (МКТУ 9/42 свободны).

## ⬜ Впереди (по приоритету)
1. **РОСТ — плотность данных в Башкирии** (главное). Чат рыбаков, ВК/ОК-группы, сарафан,
   амбассадоры. Без данных маховик и «рыба по водоёму» спят. *(На пользователе — живые отношения.)*
2. **«Рыба по водоёму» — до полной killer-фичи** (по мере данных).
3. **Распознавание рыбы по фото** — снимает трение записи, кормит маховик.
4. **Барометр телефона** — коррекция давления (техпростая, +доверие).
5. **Обучение прогноза на данных** — гибрид правила+статистика → ML.
6. **«Что сейчас можно/нельзя» по региону** — нерест/нормы/штрафы карточкой.
7. **Домены + ТЗ** (nakryuchke.com, классы 9/42) · **иконки для сторов** · **RuStore/Google Play**.
8. **Монетизация — affiliate** «купить приманку» (не paywall; только после плотности).
9. **Платформа:** PWA vs **Telegram Mini App** (обернуть готовую PWA) vs Flutter.

## 📊 Метрики (что мерить)
North Star — **уловов/записей в дневник в неделю**. Ретеншн W1/W4 (цикл рыбалки недельный).
Виральность (юзеров с 1 шэра), плотность (уловов на водоём), воронка до **второго улова**.

## ⚠️ Мониторить
**ВНИРО** («Умная рыбалка»/«Точка клёва») — единственный конкурент с той же идеей маховика +
госресурс (пока Волга). Защита: скорость, приватность, тон, ранний приход в регионы.

## 🙋 Что реально на пользователе
Офлайн (флаеры, магазины), деньги/личность/закон (домен, сторы, ТЗ), **живые отношения**
(чаты рыбаков, ВК-Клипы), вкус и решения. Всё цифровое (код, контент, миграции) — на ассистенте.
