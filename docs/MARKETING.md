# Маркетинговый плейбук «Зорьки»

Рабочие материалы для запуска (РФ/СНГ, bootstrapped, нулевой бюджет).
Цель: ~500 активных пользователей, **кластеризованных на нескольких водоёмах**,
и превращение приложения в **привычку** («открыть перед каждой рыбалкой»).
Красиво оформленная версия — в артефакте claude.ai (плейбук). Данные: 2025–2026.

## 7 главных ходов (порядок = приоритет; первые 4 — в первый месяц)
1. **Гео-фокус на один водоём** (Белая/Уфа), не «на всю Россию». Плотность > охват.
2. **Сначала ежедневная ценность, потом трафик** — прогноз «на сегодня, на твой водоём» + push накануне.
3. **Ручной посев в существующих сообществах** (rusfishing.ru, региональные VK/TG, fion.ru) — как рыбак, не как бренд.
4. **«Карточка улова»** — встроенный виральный движок (шеришь красивую картинку с брендом).
5. **RuStore ASO + заявка на фичеринг** (65,5 млн MAU, фичеринг бесплатный).
6. **Контент-мотор**: «прогноз клёва на выходные по [регион]» сериями (Дзен + TG + VK).
7. **Бартер с 3–5 микро-блогерами региона** (3–15к, реально ловят на Белой).

**Не делать:** Instagram/Reels (заблокирован, реклама вне закона), платный трафик на pre-revenue, «ещё один форум».

## Удержание (привычка)
- Модель Hook: триггер (push чт/пт вечер + утро выезда) → действие (прогноз за 0 кликов) → переменная награда (меняется день ото дня + чужие свежие уловы) → **вклад** (дневник/точки/снасти = ров).
- **Push: 1/нед базово, макс 2.** Конкретика + гео + рыба + снасть. Сегменты: хардкор (давление/окна) vs casual (погода/отдых). Разрешение — мягко, после первой ценности.
- Серии: не daily-streak (нельзя ловить каждый день), а «серия рыбалок», сезонный трекер видов, бейджи. Не наказывать за пропуск.

## Каналы по ROI
1) Форумы + FION → 2) Telegram (региональные чаты/каналы) → 3) VK (94 млн MAU) →
4) Дзен (SEO/контент) → 5) YouTube/Rutube (через блогеров) → 6) Одноклассники →
7) ASO-сторы (RuStore приоритет). **Instagram — исключить.**

## Виральные петли
1. **Карточка улова** (главная): авто-картинка после лога, шер в VK/TG/OK, бейдж «Прогноз был 4/5 ✅».
2. **Реферал с гео-бонусом**: «приведи 3 рыбаков со своего водоёма → детальный прогноз/карта».
3. **Контент из данных сообщества**: агрегат уловов → посты → новые юзеры → логи (данные = продукт И маркетинг).
4. **Конкурсы** «Улов недели по [регион]» с призом от магазина.

## Позиционирование
Одно предложение: *«Зорька» — твой знакомый рыбак в телефоне: честно скажет, будет ли завтра клёв, где, когда и на что — потому что учится на реальных уловах таких же мужиков.*
Голос: как продавец в магазине снастей — по делу, на «ты», сленг («жор», «бровка», «ни хвоста ни чешуи»).

Таглайны: «Зорька знает, когда клюёт» · «Проверь Зорьку — потом собирай снасти» ·
«Прогноз, который учится у рыбаков» · «Как спросить у бывалого — только всегда под рукой» ·
«Чтобы рыбалка была в удовольствие» (casual).

## Холодный старт: 100 → 500
- **Фаза 0** (1–2 нед): наполнить домашний водоём seed-контентом (прогнозы на 2 нед, карта точек, 10–20 своих отчётов); довести Hook-петлю и карточку улова.
- **Фаза 1** (нед 1–4): ветка на rusfishing.ru + 3–5 региональных чатов; личные приглашения; цель 100 юзеров, 30–50 логируют.
- **Фаза 2** (нед 5–12): свой TG-канал + VK-паблик с ежедневным прогнозом; Дзен-серия; бартер с блогерами; конкурс; реферал. Плотность → потом клонировать на соседние водоёмы.

## Метрики (северная звезда — удержание/привычка)
Активация (% дошёл до прогноза; % залогировал улов за 7 дн; % включил push) ·
Retention D1/D7/D30 по когортам/источникам · WAU/MAU · **pre-trip open rate** ·
K-factor + шеры карточки · **density**: активные на водоём, число водоёмов с >N.
Инструменты (бесплатно, РФ): **AppMetrica**, Яндекс Метрика (PWA), RuStore/Play Console,
Яндекс Wordstat (ключи), TGStat, Popsters, Google-таблица «когорты по источникам».

## ASO — стартовые ключи (прогнать через Wordstat)
Ядра: прогноз клёва, рыбалка, клёв, дневник рыбака, дневник уловов.
Функц.: карта рыболовных мест, календарь клёва, лунный календарь рыбака, погода/давление для рыбалки, окна клёва, когда клюёт рыба.
Виды: ловля щуки/судака/леща/карася/окуня/жереха, фидер, спиннинг.
Intent/сезон: на что клюёт рыба сегодня, где клюёт, рыбалка на выходных, зимняя/летняя рыбалка.
Гео: рыбалка Башкирия, рыбалка Уфа, рыбалка река Белая.
Название стора: **«Зорька — прогноз клёва и дневник рыбака»**.

## Готовые шаблоны

### Контент-календарь (неделя, повторять 4; тема серии по неделям: факторы → виды/снасти → точки → сезон)
Пн: итог выходных + карточка улова · Вт: разбор фактора + опрос · Ср: «на что берёт сейчас» ·
Чт: тизер + push · Пт: 🎣 ПРОГНОЗ НА ВЫХОДНЫЕ + ссылка · Сб: отчёт/конкурс · Вс: UGC-репост.
Правило: 1 статья Дзена → 3 TG + 1 VK + 1 OK + карточка.

```

Давление к субботе падает (748→742) — а это, сами знаете, жор хищника. По утру (6–9) щука и судак у бровок, на джиг тёмных тонов. Днём затишье, вечером — окунь на отмелях. Лещатникам — фидер ниже Мелькомбината, кукуруза рулит.

Это прогноз из «Зорьки» — приложение, которое я сам делаю: считает клёв по давлению, луне и погоде на конкретный водоём, плюс учится на реальных уловах наших же ребят. Дневник, карта точек — всё внутри. Бесплатно.

👉 Прогноз на твою точку — [ссылка]
Пробуйте, критикуйте. Ни хвоста ни чешуи! 🐟
#рыбалкабашкирия #рекабелая #прогнозклёва #рыбалкауфа
```

### Чек-лист запуска — кратко
Продукт: прогноз за 0 кликов · карточка улова шарится · push настроен · дневник+карта ·
водоём наполнен seed-контентом · онбординг · аналитика подключена.
Сторы: название+подзаголовок с ключами · 5–8 скринов · карточка RuStore 100% + заявка на фичеринг · «оценить» после улова.
Каналы: аккаунты на форумах/чатах прогреты · свой TG+VK оформлены · Дзен-серия · 5 блогеров + DM · промокоды · партнёр на приз.
