# 🥊 Конкуренты «На крючке» — разбор

> Собрано research-агентами (2026-08-03). Мировые карточки готовы; **российские
> конкуренты + финальный синтез «как обогнать» — дополняются** (агент дорабатывает).

## Мировые конкуренты (карточки)

### Fishbrain 🇸🇪 (лидер, компания)
- **Кто:** Fishbrain AB, Стокгольм; венчур **~$65–74M** (B Capital/Saverin, Northzone, SoftBank); ~30–60 чел.
- **Модель:** freemium, Pro **$80–155/год** + маркетплейс снастей (2019).
- **Маховик:** 14М+ уловов, AI-прогноз BiteTime, species ID (300+). Регистраций «20М» (US-центрично).
- **💥 Слабость = наш клин:** агрессивный **paywall** — карту уловов, поиск точек, статистику, прогноз загнали за подписку → массовый негатив и отток («бесполезен без Pro», «убрали бесплатное»). **РФ/СНГ у них пусто.**

### WeFish 🇪🇸 (ближайший аналог)
- **Кто:** Мурсия, ~10 чел, инвестиции скромные (~$0.4–0.7M); **куплен Pragmatix (окт 2024)**.
- **Модель:** freemium, PRO **€29.99/год** + свой интернет-магазин снастей.
- **Что:** дневник + прогноз (солунар) + соцлента + шоп. 500k+ уловов, ~4.5★. EU/Испания/ЛатАм.
- **Урок:** «всё-в-одном инди» жизнеспособен, но соло тяжело масштабировать (продались на скромном масштабе).

### FishAngler 🇺🇸 («бесплатная альтернатива Fishbrain»)
- **Кто:** Флорида, ~24 чел, **без венчура**. iOS **4.8★ / ~14k** — топ по оценкам.
- **Модель:** щедрый free + VIP ~$49.99/год (точные точки, карты Navionics, ad-free).
- **💥 Урок:** после ввода paywall **сообщество завяло** («отчёты 5-летней давности, никто не пишет»). → **UGC/сообщество держать бесплатным.**

### ANGLR 🇺🇸 (железо + логбук)
- **Кто:** Питтсбург, **$3.3M** (KB Partners, Brunswick). Bullseye — bluetooth-кнопка «лог в один клик» $29.99.
- **Слабость:** краши, «аналитика ужасна», мелкая база (4.2★ / ~634). Железо = барьер.
- **Урок:** железо — нишевый и рискованный рычаг. Наш **PWA без железа** обходит ловушку.

### Deeper 🇱🇹 (эхолот + маховик глубин)
- **Кто:** Вильнюс, 60–80 чел, PE-инвестор (Resource Partners). Приложение ~1.2–2М скачиваний.
- **Маховик как у нас**, но заперт за **железкой $160–360**. → наш сегмент «без железа, пресвода, бесплатно» им недоступен.

### Navionics 🇮🇹 (морские карты, Garmin)
- Куплен **Garmin (2017)**, 350+ чел, подписка **$50/год**, бунт из-за цены, тема **морская**. → пресная вода и СНГ открыты.

### Fishing Points 🇸🇮 (объёмный лидер)
- Инди из Словении → мини-компания. **5–11М скачиваний**, 4.4–4.7★, дешёвая подписка, Apple «App of the Day».
- **💥 Но:** тонкий логбук со **слабым сообществом**. → их дыра = наша «лента по водоёму / что ловят рядом».

### Нишевые (мировые)
- **BassForecast** (только басс) — 20k оценок 4.6★: **узкий фокус выигрывает**. **FishVerify** — AI-распознавание рыбы, 150k подписчиков. **Pro Angler** — «репорты капитанов» (живой контент). **iAngler** (НКО) — citizen-science, кормит гос-оценки запасов, но слабый UX «на альтруизме». **FishTrack** — офшорные SST-карты (Surfline).

## Российские конкуренты (наша реальная лига)

### 🥇 «Прогноз клева» (ddidev94) — лидер инди-сегмента, наш главный ориентир
- Соло/микрокоманда. **100k+ установок, 4.0★, ~11k загрузок/мес** (живой рост). Бесплатно, без рекламы.
- Умеет: погода 3-час на 5 дней из нескольких источников, **барометр телефона**, прогноз по погоде+астро, карта+трек, Луна, геомагнитка.
- **💥 Слабость:** источники погоды не сходятся, **GPS мимо на ~30 км**, давление врёт. **Нет сообщества.**
- **Наш перевес:** Open-Meteo + движок (вода-с-памятью) + honesty-строка + reverse-geocode + **лента по выездам**.

### «ТипТоп Рыбалка» (Брейслер) — самый близкий по концепции инди
- Прогноз сегодня/завтра/неделя, **подбор рыбы по водоёму региона**, Луна, дневник с фото, снасти, навигатор, офлайн, «новости от рыбаков».
- **Сильное:** пользователи хвалят **сравнение «прогноз vs факт»** — встроенный крючок удержания.
- **Перенять:** явное «сбылся ли прогноз». **Обогнать:** глубже движок (почасовой, слом погоды) + лента с рейтингом «Уважение».

### «Клёвая рыбалка» — чистое сообщество (маленькое)
- 4.1★, 3k+. Соцсеть: точки, отчёты, DIY-видео, дневник. Без сильного движка. Доказывает спрос на UGC в РФ.

### ⚠️ ВНИРО «Умная рыбалка» / «Точка клёва» — ГОСУДАРСТВЕННЫЙ маховик (следить!)
- ФГБНУ ВНИРО (госНИИ). Нормативка + состояние водоёма + виды + прогноз. Пока **только Астраханская обл. (Волга)**.
- **Та же большая идея — «маховик данных» с рыбаков** — но с админресурсом.
- **Слабости:** госмедлительность, бюрократ-UX, один регион, **недоверие** («сдам данные — прижмут по запретам»).
- **Наш козырь:** скорость, приватность, человеческий тон, приходим в регионы (Башкирия) раньше и человечнее.

### Прочие: Fishbox (платная подписка — редкость в РФ), navirit «Fishing» (низкий рейтинг), «Клёво ГИД» (правила+жалобы в Росрыболовство), «Рыбачок», «Dap Drift» (карты глубин). Низ рынка сильно фрагментирован и слаб — **нам на руку.**

**Итог по РФ:** лидер установок — ddidev94 («сухой прогноз без сообщества»), соцсети маленькие. Единственная стратегическая угроза «в нашу идею» — госВНИРО, и то региональный/медленный. **Ниша «движок + сообщество по водоёму + честность + приватность» реально свободна.**

## 🎯 Синтез — как обогнать

**Ландшафт по весу:**
- **Тяжеловесы (не бьёмся лоб в лоб):** Fishbrain (~$70M, куплен Aspira 2023), Deeper/Navionics-Garmin (железо/карты), WeFish (куплен Pragmatix 2024), госВНИРО.
- **Наша лига (инди):** ddidev94, ТипТоп, «Клёвая рыбалка», Fishbox, navirit + мелочь. **Здесь и решается.** Есть выигравшие инди (Fishing Points — миллионы).

**Что перенять:**
1. **«Прогноз vs факт»** (ТипТоп) — показывать, сбылся ли вчерашний прогноз. Дёшево, мощный крючок доверия/удержания. Сущности у нас есть — связать явно.
2. **Барометр телефона** (ddidev94) — датчик давления для коррекции. Техпростая фича, «нердам» повышает доверие.
3. **Геймификация + мягкий affiliate** (WeFish) — у нас есть «Уважение»/трофеи/«Улов недели» → к рекомендациям приманок.
4. **Species ID по фото** (Fishbrain/FishVerify — 150k подписчиков) — снимает трение записи (в планах).

**Чего избегать (их ошибки):**
- **Paywall на ядре** (Fishbrain, FishAngler) → ненависть в отзывах + **завядшее сообщество**. Ядро — бесплатно навсегда, монетизация affiliate.
- **Кривой прогноз/гео** (главная жалоба на ddidev94) — наш ответ уже есть (движок + honesty + точная гео), надо **выпячивать в позиционировании**.
- **Госдистанция/недоверие** (ВНИРО) — не превращаться в «отчётность для инспекции», давить на приватность.

**5 рычагов (инди + ИИ + локальный маховик):**
1. **Гиперлокальность** — добить один Башкортостан до плотности, где «рыба по водоёму» работает лучше любого глобального. Локальный маховик бьёт глобальный охват на своём пятачке.
2. **Скорость итераций (ИИ)** — фичи/фиксы за дни, не кварталы. Против корпоративных циклов и госбюрократии — преимущество.
3. **Честность как бренд** — честный балл, honesty-строка, нерест-предупреждение. Доверие нельзя купить.
4. **Приватность** — точную точку видит только владелец; контраст и с Fishbrain (данные=товар), и с ВНИРО (страх слежки).
5. **Глубина движка при нуле бюджета** — почасовой, вода-с-памятью, слом погоды, Луна — сложнее типичных РФ-инди, без сервера и денег.

**Позиционирование (чтобы не биться лоб в лоб):**
НЕ глобальная соцсеть (Fishbrain), НЕ железо/карты (Deeper/Navionics), НЕ «сухой прогноз» (ddidev94).
**ДА:** *«Показывает, что реально клюёт на твоём водоёме сегодня — по приметам и по уловам таких же рыбаков рядом, без подписок и без слежки за твоей точкой»* — пресновод РФ/СНГ, регион за регионом, старт с Башкортостана.

**⚠️ Главный риск для мониторинга:** ВНИРО («Умная рыбалка»/«Точка клёва») — единственный с той же идеей маховика + админресурс. Защита: скорость, тон, приватность, ранний приход в регионы.
