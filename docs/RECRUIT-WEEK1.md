# 🎣 Набор первых рыбаков — неделя 1 (Башкирия)

**Что рекламируем:**
- Приложение: **https://kressent.github.io/zorka/**
- Бот: **@nakryuchke_fish_bot** (пишешь водоём → прогноз)
- Канал: **@nakryuchke_rb** (каждое утро дайджест)

**Главный принцип:** не «скачай приложение», а **«вот тебе польза»**. Рыболовное
сообщество не терпит рекламу — заходим через прогноз, отчёты, ответы по делу.
Цель недели — **не охват, а первые 5–10 живых людей** и пара реальных уловов в дневнике.

**Что важнее всего:** проси людей **записать улов** в дневник. Каждый улов делает
прогноз точнее для всех — это наш «маховик». Без уловов killer-фича спит.

## 📅 План на неделю (низкая нагрузка, по 20–30 мин/день)

**День 1 — свои.** Напиши текст A **10–15 знакомым рыбакам** в личку. Попроси 2–3 самых
активных переслать «своим». Это самый тёплый и конверсионный канал.

**День 2 — разведка.** Найди и вступи в **5–7 Telegram-чатов/групп** по рыбалке РБ.
Поиск в Telegram: «рыбалка Башкирия», «рыбалка Уфа», «Салават рыбалка», «Павловка рыбалка»,
«Нугуш рыбалка». Пока только **читай**, вникай, ответь пару раз по делу (без ссылок).

**День 3 — польза в чатах.** В 1–2 чатах, где освоился, ответь на реальный вопрос
«куда/когда» текстом B. Не спамь, только по теме.

**День 4 — форумы.** Зарегься на fion.ru / rusfishing.ru / местном форуме, найди ветку
по РБ → полезный пост (текст D) + подпись со ссылкой.

**День 5 — пост-польза.** В 1–2 самых живых чатах — текст C. Разнеси по дням, не везде
в один день.

**Выходные — прогноз на выходные.** Текст E в чатах и в канал. Пятница/суббота утром —
пик интереса «куда ехать».

**Каждый день:** 1 ответ по делу в каком-нибудь чате + следи за своим каналом
(отвечай на комменты). Живой «синоптик района» набирает доверие быстрее любой рекламы.

**Когда восстановишь ВК/ОК:** те же тексты (A/C/E) в группы «Рыбалка Башкирия»,
«Спиннинг РБ», «Рыбаки Башкортостана» + районные. ОК — аудитория 40+, очень рыболовная.

## ⚖️ Чтобы не забанили
- **80% пользы, 20% ссылки.** Кинул ссылку без пользы → бан.
- **Стань своим:** сначала поучаствуй (ответь, выложи отчёт/фото), потом упоминай.
- **Не дублируй** один текст в 10 чатов за час — разнеси по дням, чуть меняй формулировки.
- **Отвечай на вопросы** новичков искренне — это лучший «маркетинг».
- **Проси уловы:** «поймал — отметь в дневнике, прогноз станет точнее для всех».

## 🎯 Метрика недели 1
Не гонись за числами. Успех = **5–10 живых людей** в канале/приложении + **первые уловы
в дневнике**. С них начнёт крутиться маховик — дальше сарафан и «рыба по водоёму».
