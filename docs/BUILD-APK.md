# Сборка APK для RuStore / Google Play (TWA)

Наше PWA заворачивается в Android-приложение через **TWA** (Trusted Web Activity) —
это официальный способ Google: приложение = наш сайт в полноэкранной обёртке, без
браузерной адресной строки. Обновляется само вместе с сайтом (код тянется с
`kressent.github.io/zorka/`), пересобирать APK при каждом изменении НЕ нужно.

## Готовность (проверено 2026-08-06)
- ✅ HTTPS-хостинг (GitHub Pages)
- ✅ `manifest.webmanifest`: name, short_name, description, иконки 192/512 (+maskable), `display: standalone`
- ✅ Service worker (офлайн)
- ⚠️ **Один блокер — Digital Asset Links** (см. ниже). Без него TWA покажет адресную строку сверху.

## Блокер: Asset Links должны лежать в КОРНЕ домена
Для проверки, что приложение владеет сайтом, Android читает файл
`https://kressent.github.io/.well-known/assetlinks.json` — именно в **корне**
`kressent.github.io`, а не в `/zorka/`. Мы публикуем в подпапку `/zorka/`, корень —
отдельный «user page».

**Два пути (выбрать один):**

| | Бесплатный (сейчас) | Свой домен (лучше для бренда) |
|---|---|---|
| Что делать | Создать репозиторий **`kressent.github.io`** (user page), положить туда `.well-known/assetlinks.json` | Купить `nakryuchke.com`, привязать к Pages, всё окажется в корне |
| Плюсы | 0 ₽, 10 минут | Красивый адрес в сторе, чистый корень |
| Минусы | Адрес остаётся `kressent.github.io/zorka` | ~1800 ₽/год + настройка DNS |

👉 Рекомендация: **начать с бесплатного пути** (user-page репозиторий), домен —
когда захочешь заняться брендом. Оба разблокируют сборку.

## Сборка — через PWABuilder (без установки Android SDK)
Самый простой путь для не-разработчика. Всё в браузере, бесплатно.

1. Открой **https://www.pwabuilder.com**
2. Вставь адрес: `https://kressent.github.io/zorka/` → **Start**
3. Проверит манифест/SW (у нас зелено) → вкладка **Package For Stores** → **Android**
4. Настройки пакета:
   - Package ID: `com.nakryuchke.app` (или `io.github.kressent.zorka` — **запиши и не меняй никогда**, это идентификатор в сторе)
   - App name: `На крючке`
   - Launcher name: `На крючке`
   - Signing key: **Create new** (PWABuilder сгенерит) — **СОХРАНИ .keystore и пароли!** Без них не выпустить обновление.
5. **Download** → получишь ZIP: внутри `.apk` (для теста), `.aab` (для сторов),
   `assetlinks.json` и сам keystore.
6. Возьми `assetlinks.json` из архива → положи в репозиторий `kressent.github.io`
   по пути `.well-known/assetlinks.json`, запушь. Проверь, что открывается:
   `https://kressent.github.io/.well-known/assetlinks.json`

## Публикация
- **RuStore** (первым — наша аудитория): регистрируешь аккаунт разработчика
  (физлицо/самозанятый — можно), заливаешь `.aab`/`.apk`, описание берём из
  `docs/STORE-LISTING.md`, политика — `privacy.html`. Товарный знак НЕ требуется.
- **Google Play** (вторым): аккаунт разработчика $25 разово, тот же `.aab`.
