# ☁️ Бэкенд Зорьки (Supabase) — как подключить

Это **старт «маховика данных»**: аккаунты + облако + общая база уловов
(данные больше не заперты на одном телефоне; разные устройства; будущее сообщество
и рейтинг приманок). Пока ключей нет — приложение работает на `localStorage`, всё ок.

## Что нужно от тебя (~5 минут)
1. Заведи бесплатный аккаунт на **supabase.com** → **New project** (регион ближе — EU/Central).
   Придумай пароль БД, дождись создания (~2 мин).
2. Открой проект → **SQL Editor** → вставь и запусти файл [`schema.sql`](./schema.sql)
   (создаст таблицы уловов/мест/снастей + приватность + RLS).
3. Открой **Project Settings → API** и скопируй:
   - **Project URL** (вида `https://xxxx.supabase.co`)
   - **anon public** ключ (публичный, не секретный — ему можно быть в клиенте)
4. Пришли мне эти две строки (или впиши сам в [`js/config.js`](../js/config.js)).

## Что дальше сделаю я
- Подключу клиент Supabase, вход по email/OTP (без паролей — проще для рыбаков).
- Перенесу дневник/места/снасти из `localStorage` в облако + синхронизацию между устройствами.
- Включу **общую ленту уловов рядом** и заложу **рейтинг приманок** (наш дифференциатор).
- Точные координаты — приватные; в общей ленте — огрублённые (уже в схеме, триггер `fuzz_coords`).

## Заметки
- `anon`-ключ публичный — безопасность держится на **RLS** (уже в схеме): каждый видит/правит только своё, публичное — только чтение.
- Бесплатного тарифа Supabase надолго хватит на старте.
