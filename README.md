# 🎣 Зорька

**Прогноз клёва, дневник рыбалок и карта мест для России и СНГ.**

«Зорька» — та самая утренняя/вечерняя зорька, лучшее время ловли. Приложение
показывает, **какая рыба сегодня клюёт лучше всего, когда и на что**, с учётом
погоды, давления, температуры воды, ветра, луны и сезона — и помогает вести
дневник уловов, хранить снасти и отмечать места.

> Это **первая рабочая версия** (веб-PWA). Прогноз работает на экспертных
> правилах + живой погоде Open-Meteo. Обучение на реальных уловах сообщества,
> сервер, аккаунты и спутниковая карта — следующие этапы (см. `docs/ROADMAP.md`).

## Быстрый старт

PWA требует http (просто открыть файл нельзя). Нужен только Node.js:

```bash
node tools/serve.js       # → http://localhost:8080
```

Открой ссылку в браузере (на телефоне — Chrome, «Добавить на главный экран»).

## Тесты

```bash
node test/engine.test.js      # движок прогноза (тянет живой Open-Meteo, есть офлайн-синтетика)
node test/ui.smoke.test.js    # рендер всех экранов без браузера
node test/serve.check.js      # отдача статики с верным MIME
```

## Структура

```
index.html            оболочка
css/style.css         дизайн-система «Дневной альманах» (light-only)
js/
  data.js             база из 15 видов рыб — «мозги» (ручная настройка)
  astro.js            фазы луны и время солнца (без сети)
  weather.js          Open-Meteo (без ключа), кэш 3 ч (офлайн)
  score.js            движок прогноза (правила + луна + мутность + жор)
  state.js            состояние + настройки (localStorage)
  locations.js        города/места + геолокация
  diary.js            дневник (вес по каждой рыбе, авто-итог)
  tackle.js           комплекты снастей + учёт остатка приманок
  ui.js               рендер экранов и модалок
  app.js              точка входа
manifest.webmanifest  PWA
sw.js                 service worker (офлайн-first)
docs/                 SPEC (все решения) и ROADMAP
```

## Деплой

Пока — как статику: перетащить папку на **Netlify** (или GitHub Pages). Целевой
канал для РФ — **RuStore** (обёрткой), см. ROADMAP.

## Стек

Чистый HTML/CSS/JS (ES-модули), без сборки и зависимостей. Погода — Open-Meteo.
Данные — пока `localStorage`; общий сервер (Supabase) — на этапе сообщества.
